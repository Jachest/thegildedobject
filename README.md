# The Gilded Object website

Static site for thegildedobject.com. Open `index.html` in a browser to view it locally.

## Putting it on GitHub

1. Create a new repository on GitHub and copy everything in this folder into it.
2. In the repository's Settings, open Pages and publish from the main branch.
3. Set the custom domain to `thegildedobject.com` and add the DNS records GitHub shows you at your domain registrar.

The forms and the card payment are not connected yet. `CLAUDE.md` lists what is left to do and holds the brand rules.
